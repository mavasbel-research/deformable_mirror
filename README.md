# deformable_mirror

![language](https://img.shields.io/badge/language-Lean-MATLAB-blue) ![status](https://img.shields.io/badge/status-active-brightgreen)

> Simulation of a hysteretic deformable mirror: influence matrices, electrode layouts, Preisach actuators, control and Zernike wavefront reconstruction (MATLAB).

## Features

- Influence-matrix generation for configurable electrode layouts
- Preisach-actuator hysteresis per channel with closed-loop control examples
- Zernike wavefront reconstruction for optical evaluation
